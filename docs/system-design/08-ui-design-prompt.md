# 角色与任务

你是一位资深产品设计师,擅长 macOS 原生应用与流媒体播放器界面。请为一款名为 **DanmakuEmby** 的 macOS 桌面客户端设计一套高保真 UI 设计稿。这是一个连接自建 Emby 媒体服务器、用于浏览和播放影视/番剧、并在播放时叠加显示弹幕的播放器(类似 Infuse / IINA,但带 B 站式弹幕)。请输出每个核心界面的高保真视觉稿,并保持一致的设计系统。

# 产品功能(界面需覆盖)

1. 添加并管理多个 Emby 服务器(地址 + 用户名 + 密码登录,可切换)。
2. 浏览媒体库(电影 / 剧集 / 动漫),支持分页、排序、筛选。
3. 媒体详情(电影或剧集,剧集含分季与剧集列表、继续观看进度)。
4. 全局搜索。
5. 播放器(核心):视频播放 + **弹幕叠加显示** + 播放控制条 + 音轨/字幕轨切换 + 切集。
6. 弹幕设置(透明度、字号、滚动速度、显示区域、密度、按类型/关键词屏蔽)。
7. 弹幕匹配:自动匹配状态提示 + 手动搜索匹配(可在弹弹play / 哔哩哔哩 / 腾讯视频三个源里搜番、选季、选集)。
8. 应用设置(播放设置、弹幕默认值、弹幕源管理、平台账号登录入口)。

> 说明:本应用**只显示弹幕,不发送弹幕**,所以播放界面不需要弹幕输入框。

# 平台与技术约束

- 目标平台:**macOS**(Electron 实现,但要做出原生 mac app 的观感)。
- **原生无边框窗口**:隐藏系统标题栏,保留左上角红绿灯交通灯按钮;顶部留出可拖拽区域。
- **毛玻璃 / 材质感(vibrancy)**:侧边栏、浮层、控制条使用半透明模糊材质,透出背景内容,营造层次与深度。
- 主要面向桌面尺寸,需给出窗口宽度 **1280px 和 1440px** 两档;播放器界面额外给出全屏沉浸态。
- 仅做**深色主题**(影院深色),无需浅色版。

# 视觉方向

**影院深色 + 玻璃拟态(cinematic dark + glassmorphism)**,参考并对标以下优秀主流播放器的品质感(取其神,不要照抄):
- **Infuse**(海报墙、整屏模糊剧照背景、优雅排版与层次)
- **IINA**(macOS 原生播放器控制条、半透明 OSC、克制的图标)
- **Apple TV app**(大幅艺术图、平滑过渡、留白节奏)
- 弹幕设置浮层的交互可参考 **哔哩哔哩网页播放器**,但要做得更精致、更原生。

整体气质:**高级、沉浸、克制而有层次**。内容(海报、剧照)是主角,UI 退居其次。避免廉价模板感:不要均匀的卡片网格配统一阴影,不要居中标题配渐变色块的套路 hero。要有清晰的尺度对比、有节奏的留白、通过叠层与模糊营造的真实深度。

# 设计令牌(请严格遵循)

## 配色(深色,使用 oklch 思维,可输出对应 hex)
- 背景基色 `--bg`:近黑带微蓝冷调,约 oklch(14% 0.02 260)
- 二级背景 `--bg-elevated`:略亮,约 oklch(18% 0.02 260)
- 玻璃面板 `--surface-glass`:半透明深色 + 背景模糊(rgba 黑 ~55% + blur 30px)
- 主文本 `--text`:接近纯白但不刺眼,oklch(96% 0 0)
- 次要文本 `--text-muted`:oklch(70% 0.01 260)
- 三级/占位文本:oklch(50% 0.01 260)
- **强调色 `--accent`(电光蓝/靛蓝)**:oklch(65% 0.19 255),用于:主操作按钮、播放按钮、进度条已播部分、选中态、聚焦环、关键数据。
- 强调色辉光:在播放按钮、聚焦元素上加柔和外发光(accent 色低透明度 blur)。
- 分隔线:白色 8% 透明度。
- 状态色:成功 oklch(72% 0.17 150)、警告 oklch(78% 0.16 75)、错误 oklch(63% 0.21 25)。
- 弹幕匹配状态徽标用上述状态色。

## 字体
- UI 与正文:**SF Pro Text / SF Pro Display**(macOS 系统字体)。
- 中文:**PingFang SC**。
- 最多两个字族;标题用 Display、正文用 Text;数字与时间码可用等宽变体(SF Mono)。
- 字号采用流式比例:正文 13–15px,二级标题 20–24px,页面/英雄标题 32–56px,强烈的尺度对比建立层次。

## 间距、圆角、动效
- 间距用 4 的倍数节奏,板块之间留白要大、要有呼吸感,而不是处处等距。
- 圆角:卡片/海报 10–12px,浮层/面板 16px,按钮 8–10px,胶囊控件用全圆角。
- 动效:只动 transform / opacity;缓动用 ease-out-expo(cubic-bezier(0.16,1,0.3,1));
  - 海报 hover:轻微放大(scale 1.04)+ 提升阴影 + 显示标题遮罩;
  - 播放控制条:鼠标移动淡入,静止数秒淡出;
  - 页面切换:剧照背景交叉淡入。

# 需要输出的界面(逐屏规格)

## 1. 引导 / 添加服务器
- 首次启动的居中卡片(玻璃面板):应用 logo/名称、服务器地址输入、用户名、密码、"连接"主按钮(强调色 + 辉光)。
- 背景:大幅模糊的影视剧照拼贴 + 暗角,营造影院感。
- 已有服务器时:左侧服务器列表(名称 + 在线状态点 + 头像),可切换/新增。
- 状态:输入聚焦(强调色聚焦环)、连接中(按钮 loading)、错误(地址无效/认证失败的友好提示)。

## 2. 主框架(App Shell)
- **左侧毛玻璃侧栏**(约 240px):顶部当前服务器切换器;导航项(首页、电影、剧集、动漫、搜索、设置),选中项用强调色高亮 + 左侧指示条;底部当前用户。
- 顶部:可拖拽区 + 红绿灯留白;右侧可放搜索框/筛选。
- 侧栏可折叠为图标态(给出展开与折叠两种)。

## 3. 首页 / 资源库网格
- 顶部一个大幅 **英雄横幅**:精选内容的整屏剧照 + 标题 + 简介 + "播放/继续观看"按钮(强调色)。
- 下方分排横向滑动的内容行:"继续观看"(带进度条的缩略图)、"最近添加"、各媒体库。
- 海报卡:封面图 + hover 显示标题/年份/评分遮罩 + 角标(如未读集数、弹幕可用标识)。
- 提供一个纯网格的"媒体库浏览"视图:顶部筛选/排序工具条(类型、年份、排序),海报瀑布/规整网格,无限滚动。
- **不要**做成均匀死板的卡片墙——用英雄区与内容行制造编辑式层次。

## 4. 媒体详情页
- 顶部整屏 **模糊剧照背景 + 暗角渐变**,前景左侧竖版海报,右侧:标题(大字号)、年份/时长/评分/类型胶囊、简介、主创信息。
- 主操作区:大号"播放"按钮(强调色 + 辉光)、"继续观看 第X集 12:34"、收藏、标记已看。
- **弹幕状态徽标**:显示该内容弹幕匹配情况(如"弹幕已匹配 · 弹弹play 1.2万条"绿色,或"未匹配弹幕 立即匹配"可点)。
- 剧集页:分季下拉/标签 + 剧集列表(横向缩略图卡:集号、标题、时长、观看进度条、简介);电影页则为相关推荐行。

## 5. 搜索
- 顶部大搜索输入(聚焦时强调色环);
- 结果分组(剧集/电影/动漫),海报网格;
- 空态(插画 + 提示)与无结果态。

## 6. 播放器(核心界面,重点设计)
- 视频铺满,深色沉浸;**弹幕从右向左滚动叠加在画面上方**(请在稿子里真实画出几条不同颜色、不同位置的弹幕,体现真实观感与可读性——弹幕带细描边保证在亮画面上也清晰)。
- **底部毛玻璃控制条(OSC)**,鼠标移动时淡入:
  - 进度条(已播为强调色 + 圆形滑块 + 缓冲段;hover 显示缩略图预览与时间);
  - 左侧:播放/暂停、上一集/下一集、音量;
  - 中部:当前时间 / 总时长(等宽数字)、剧集标题;
  - 右侧:**弹幕开关(高亮态/关闭态要明显区分)**、弹幕设置、音轨选择、字幕选择、画质/播放速度、画中画、全屏。
- 顶部浮层(淡入):返回按钮、剧集标题、投屏等。
- 给出三态:**控制条显示态、控制条隐藏的纯净观看态、弹幕关闭态**。

## 7. 弹幕设置浮层
- 从播放器右侧滑入的毛玻璃面板(不打断观看):
  - 总开关;
  - 不透明度滑块、字号滑块、滚动速度滑块、显示区域(顶部/半屏/全屏分段控件)、密度滑块;
  - 屏蔽类型(滚动/顶部/底部 多选)、关键词屏蔽(可添加标签);
  - 实时预览:调整时画面上的弹幕随之变化。
- 控件风格统一:滑块轨道用强调色填充,分段控件选中态强调色。

## 8. 弹幕手动匹配浮层
- 模态/侧滑面板:
  - 顶部:当前播放内容信息 + 三个弹幕源标签页(**弹弹play / 哔哩哔哩 / 腾讯视频**),每个标签可带登录状态点;
  - 搜索框(预填 Emby 剧名);
  - 搜索结果列表(番剧/影片:海报缩略图、标题、年份、集数、来源标识),选中后展开剧集列表选具体集;
  - 底部:"应用此匹配"主按钮;已匹配项显示对勾。
- 状态:未登录(引导"前往登录"以读取该平台 Cookie)、加载中、无结果、地区/会员受限提示。

## 9. 应用设置
- 左侧分组导航(播放、弹幕、弹幕源、账号、关于),右侧表单区:
  - 播放:硬件解码开关、最大码率、默认音轨/字幕语言;
  - 弹幕:上述渲染项的全局默认值;
  - 弹幕源:已启用的源列表(弹弹play/B站/腾讯,可拖拽排序、启停、配置),manifest 更新状态;
  - 账号:B站 / 腾讯 登录入口(用于读取弹幕 Cookie)及登录状态;
  - 设置项采用分组卡片 + 开关/滑块/下拉,清晰留白。

# 组件与状态要求
- 所有可交互元素都要有清晰的 hover / focus / active / disabled / selected 状态,且看起来是"被设计过的"(强调色聚焦环、轻微位移或辉光)。
- 列表/网格给出加载骨架屏、空态、错误态。
- 图标统一线性风格、视觉重量一致(参考 SF Symbols 气质)。
- 注意可读性:弹幕、控制条文字在明亮画面上需有足够对比(描边/底纹)。

# 交付物

- 一页设计系统总览:配色、字体层级、按钮/输入/滑块/标签/卡片等核心组件及其状态。
